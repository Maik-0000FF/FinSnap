# Security policy

## Supported versions

Fixes go into the latest release only.

## Reporting a vulnerability

Please do not open a public issue for a security problem. Report it privately on GitHub: open the [Security tab](https://github.com/Maik-0000FF/FinSnap/security) of the repository and choose **Report a vulnerability**.

Say which version of FinSnap and of FreeCAD you use and how to reproduce the problem.
